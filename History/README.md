# History: the working conversation behind the analyses

Rob Williams's working session with Claude (Opus 5.5), 21–24 November 2026, kept so that readers can see how models were chosen, with the logic and the illogic. Rob, 24 November 2026: "Useful for readers to see our model selection process and logic/illogic."

- **The same conversation in two formats:** Markdown to read, JSON for programs. Dates are UTC.
- **Edited.** Only the messages and replies are here. Left out: tool calls and their output, images, personal messages, and passages on another private project and on machine setup (marked "[omitted]"; whole paragraphs were removed by keyword, so some replies have gaps). It is not a verbatim record.
- **Read it as a record, not as results.** Many statements were corrected later in the same conversation, for example that the Vita1a effect in BXD acts "only at T770", and a P value for Vita1b × nicotinamide quoted alone. The files in `notes/` are the current versions.
- **The mapping was exploratory throughout:** models were chosen while maps were being looked at.
